# 内容索引与页面身份

`SiteIndex.ByID` / `ByURL` 保留可直接访问的生产内容，包括 Unlisted。公开时间列表只包含 Public；预览模式可以额外显示 Draft，缺少日期的草稿排在有日期文章之后。

发布时间与更新时间分别排序：有值优先、日期倒序、稳定 ID 升序。独立页面单独保存，无日期页面仍按稳定 ID 排列。排序不读取文件时间。

分类聚合包含文章所属分类的祖先，同一分类按文章 ID 去重。分类、标签与归档只从 Public 文章产生；未使用的元数据项不会显示在总览。展示名与父分类变化不改变分类/标签的 URL 和身份。

分类和标签的配置文件由 `config.yaml` 的 `paths.taxonomies` 指定，默认是 `taxonomies.yaml`。文章的分类、标签均只保留与配置中稳定 ID 的交集，重复项去重。未配置的标签不会显示在文章下方，也不会生成标签页；已配置但未被 Public 文章使用的标签不进入公开标签列表。仅在 Unlisted 或 Draft 中使用的已配置标签，在文章下方显示为普通文字。

文章未填写分类时正常生成；填写多个分类时，只要至少一个已配置，就按已配置的分类生成。填写了分类但全部未配置的文章，在生产和预览中都排除，不占用 ID、URL 或 aliases，也不进入首页、更新、归档、RSS、站点地图和统计清单。重新配置其分类后，下次构建自动恢复该文章。

每个列表第一页使用基础路径，后续页追加 `page/{n}/`；分页身份为 `{基础ID}:page:{n}`。分类使用 `category:{id}`，标签使用 `tag:{id}`，归档使用 `archive:{yyyy}` 或 `archive:{yyyy}-{mm}`。无内容时保留首页和系统总览，不生成空的后续页。

上一篇/下一篇按 Public 文章的发布时间建立，与更新时间列表分离。RSS 的 GUID 使用稳定内容 ID；RSS 和 Sitemap 排除 Unlisted/Draft，Sitemap 另排除 404。生成链接均使用规范 URL。

重定向文件包含 Nginx `map` 的字面量条目，覆盖无尾斜杠、`index.html` 和历史 aliases；目标只能为内容的当前规范 URL。由部署示例统一返回 301 并保留 query，生成器不修改或重载 Nginx。
