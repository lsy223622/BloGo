# Markdown 语法

正文使用 Goldmark，启用 GFM 与脚注：标题、段落、链接、图片、引用、列表、围栏/缩进代码块、表格、任务列表、删除线及 `[^name]` 脚注。Chroma 在构建时高亮代码，未知语言按纯文本处理。

标题自动生成稳定且去重的锚点，目录包含标题层级、锚点和纯文本。原生 HTML 属于作者可信内容，保留其 DOM 和脚本；普通元数据仍须经模板上下文转义。

公式支持单行 `$...$` 与独占行的 `$$` 块。公式先作为独立 AST 节点保留 TeX 源码，供自托管 KaTeX 增强；禁用 JavaScript 时仍可阅读原始公式。代码内部的美元符号不参与公式解析。

非空手写摘要优先。自动摘要读取第一个有意义的 AST 正文段落，排除代码、公式、HTML 标签、script/style 文本，解码文本实体并合并空白，再按配置的 Unicode 字符数截断。HTML 源页面使用手写摘要，缺省为空。

回归样例见 `internal/markdown/markdown_test.go`；基础示例内容包含代码与公式。
