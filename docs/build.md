# 构建输入与快照

输入由内容、模板、静态资源、配置和分类标签文件组成。扫描按稳定相对路径及文件内容 SHA-256 计算整体指纹，同时包含当前构建程序二进制的摘要和预览选项；文件时间不决定是否变化。输出、release、数据库和报告不属于扫描输入。

每次构建先创建私有快照，复核其指纹与扫描一致，再仅从快照解析和渲染。扫描后源文件变化会使本次快照失败；快照完成后的编辑由下一次扫描发现。配置文件若在解析后发生变化，必须重新加载，不能混用旧配置对象与新文件字节。

输入根目录和文件必须是普通目录/文件。源目录内的符号链接、设备文件、管道和未允许的文件类型明确失败。快照根目录为进程创建的私有目录，构建结束后清理。

执行独立生产构建：

```sh
go run ./cmd/blog build --config config.yaml --output output/site
```

输出包含 `public/` 与 `meta/`。public 保存页面、静态资源、RSS、Sitemap 和 robots；meta 保存 Manifest、输入指纹及待人工应用的 Nginx 重定向条目。每个 HTML 页面对应一个 Manifest 条目；无日期页面不伪造发布时间，生产输出排除 Draft。

先在同级临时目录完整生成和校验，成功后才替换独立输出目录。已有非空输出必须能识别为先前的 BloGo 构建，防止把任意目录当成输出清理。重建不保留已删除内容的旧文件，失败保留旧输出。此命令不切换生产 current。

本地图片、脚本、样式和字体等资源缺失会失败。指向不存在内容的链接默认记录警告，`build.strict_links: true` 时失败。校验只查输出集合，不对外部链接发起网络请求。
