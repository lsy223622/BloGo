# 构建输入与快照

输入由内容、模板、静态资源、配置和分类标签文件组成。扫描按稳定相对路径及文件内容 SHA-256 计算整体指纹，同时包含当前构建程序二进制的摘要和预览选项；文件时间不决定是否变化。输出、release、数据库和报告不属于扫描输入。

每次构建先创建私有快照，复核其指纹与扫描一致，再仅从快照解析和渲染。扫描后源文件变化会使本次快照失败；快照完成后的编辑由下一次扫描发现。配置文件若在解析后发生变化，必须重新加载，不能混用旧配置对象与新文件字节。

输入根目录和文件必须是普通目录/文件。源目录内的符号链接、设备文件、管道和未允许的文件类型明确失败。快照根目录为进程创建的私有目录，构建结束后清理。

执行独立生产构建：

```sh
go run ./cmd/blog build --config config.yaml --output output/site
```

输出包含 `public/` 与 `meta/`。public 保存页面、静态资源、RSS、Sitemap 和 robots；meta 保存 Manifest、输入指纹及待人工应用的 Nginx 重定向条目。每个 HTML 页面对应一个 Manifest 条目；无日期页面不伪造发布时间，生产输出排除 Draft。

先在同级临时目录完整生成和校验，成功后才替换独立输出目录。已有非空输出必须能识别为先前的 BloGo 构建，防止把任意目录当成输出清理。重建不保留已删除内容的旧文件，失败保留旧输出。此命令不切换生产 current。

本地图片、脚本、样式和字体等资源缺失会失败。指向不存在内容的链接默认记录警告，`build.strict_links: true` 时失败。校验只查输出集合，不对外部链接发起网络请求。

Linux 上 `blog publish --config config.yaml` 先取得 current 目标的非阻塞进程锁，构建和复核完整 release，再通过同一文件系统内的临时符号链接与原子 rename 切换 current。锁覆盖整个发布，竞争者明确失败；进程退出释放原生锁，锁文件保留以避免 inode 竞争。

release 根目录与 public 可遍历读取，meta 为 0750、内部文件为 0640；部署时让构建器主组为 Manifest 读取组，统计/报告用户加入该组，Nginx 不加入。成功切换后按 `keep_releases` 保留完整版本，始终包含当前版本；清理错误作为警告保留供处理，不撤回已成功的切换。

发布还保留 current 与最近完整版本（最多 keep_releases 个已有版本）HTML 直接引用的受管哈希 CSS/JS。这样客户端已拿到旧 HTML 时，切换后的 CSS/JS 请求仍能完成。继承但未被旧 HTML 直接引用的哈希不会继续传播，窗口外的客户端需要刷新。独立 build/dev 不携带发布历史资源。启用统计的任何页面都要求 assets/stats.js 存在，缺失时构建失败并保留旧版本。

人工回滚先停止 watcher，核对保留版本的 public 与 meta，再用新的临时链接原子替换 current。确认源内容与选定版本一致后恢复 watcher，避免随后自动发布覆盖回滚结果。部署命令及权限设置见后续部署说明。

`blog watch --config config.yaml` 持有同一个生产锁，默认每 60 秒串行扫描。重启时从 current Manifest 读取最后成功指纹；无变化时跳过。确定性内容错误按失败指纹抑制重复构建和日志，输入变化后重试；I/O 或发布故障会在后续轮次重试，同类日志每分钟最多一条。手动 publish 可主动重建相同输入。配置内容会重新加载，修改 current 目标需要重启 watcher 以重新取得对应锁。

本地预览：

```sh
go run ./cmd/blog dev --config config.yaml --output output/dev --listen 127.0.0.1:8080
```

预览使用独立输出，不切换生产 current，也不取得生产发布锁。默认回环监听，草稿可见；每秒检查输入，成功重建后浏览器通过修订号检测自动刷新。构建错误保留上次可读输出。规范 URL 的 301 和 query 保留与生产配置一致，未知地址及 `/404/` 返回 404，目录列表与 meta 不经预览提供。

自动刷新脚本只插在 tokenizer 确认的 body 结束标签前；允许省略 body 结束标签的作者文档仍按原文提供，不在不安全位置插入脚本，这类文档可手动刷新。2026-10-23 已使用真实 `blog dev`、独立内容夹具和 Edge 核对：修改内容后 build_id 改变，未手动导航的文章页面自动显示新段落。
