# 构建输入与快照

输入由内容、模板、静态资源、配置和分类标签文件组成。扫描按稳定相对路径及文件内容 SHA-256 计算整体指纹，同时包含当前构建程序二进制的摘要和预览选项；文件时间不决定是否变化。输出、release、数据库和报告不属于扫描输入。

每次构建先创建私有快照，复核其指纹与扫描一致，再仅从快照解析和渲染。扫描后源文件变化会使本次快照失败；快照完成后的编辑由下一次扫描发现。配置文件若在解析后发生变化，必须重新加载，不能混用旧配置对象与新文件字节。

输入根目录和文件必须是普通目录/文件。源目录内的符号链接、设备文件、管道和未允许的文件类型明确失败。快照根目录为进程创建的私有目录，构建结束后清理。
