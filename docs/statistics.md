# 统计与私有报告

统一服务提供 `POST /api/events` 与 `/data/stats.json`，进程内部刷新报告和清理过期数据。运行数据位于私有 `data/`；数据库为 `statistics/stats.db`，持久密钥为 `statistics/visitor.key`，私有报告为 `private/report.html`。本地预览使用独立的 `data/dev/` 数据，不与正式统计混用。

## 汇总与去重

SQLite 使用 WAL、5 秒 busy timeout 和单写连接。每个浏览事件的幂等标记、每日访客标记、站点 PV/UV、逐页 PV、来源聚合以及可选明细在同一短事务中提交，任何一步失败全部回滚。

数据库使用 schema 2。现有 schema 1 在单个事务中迁移，保留汇总和去重记录；未知版本及非空无版本数据库明确失败。内容不存入数据库，历史统计不依赖当前文章的外键。迁移不更换访客密钥。

每日 UV 使用 `HMAC-SHA256(key, day + NUL + visitor_id)` 的 32 字节摘要，不保存浏览器原始访客 ID，不以 IP 去重。密钥首次创建后持续复用；缺损数据必须检查和恢复，不能用重建密钥冒充修复。7 天和 30 天 UV 是逐日 UV 之和。

## 请求协议与客户端地址

事件仍只有五个字段：`v`、`event_id`、`page_id`、`visitor_id`、`referrer_host`。JSON 最多 2 KiB，未知、重复或空字段失败；事件和访客标识为浏览器生成的 32 位十六进制字符串。当前清单必须允许该页面统计，来源和页面上下文必须符合站点 origin。草稿不采集。

来源仅保留主机名，站内导航记为 internal，无来源记为 direct，不保存完整来源 URL、查询参数或片段。延迟的旧页面统计脚本不能为当前页重复计数。

仅当直接连接对端在 `server.trusted_proxies` 中时解析 X-Forwarded-For；从右向左跳过可信代理，使用最近的不可信节点。陌生来源的头无效，非法可信链保守回退连接对端。解析结果由服务端请求上下文传给采集器，JSON 不能自报可信 IP。

保留全局限制，并增加来源限制：每个 IP 突发 40 次、每秒补充 20 次；最多 4096 个来源桶，空闲 10 分钟回收。来源桶不构成永久逐访问记录。

## 可选详细统计

`stats.details.enabled` 默认 false，`retention` 默认 168h。开启后新增有效事件会记录：

- 服务端时间、事件 ID、稳定页面 ID，以及浏览当时的规范 URL 和标题。
- 经可信代理规则解析的 IP、来源主机名、当日访客摘要。
- 最多 512 字节的 User-Agent、Accept-Language 中优先级最高的语言。
- 由锁定的 [go-useragent](https://github.com/medama-io/go-useragent) 解析的粗粒度浏览器、操作系统和设备类别；无法识别时为 Unknown。

不增加浏览器探测、地理定位、营销归因、会话时长、滚动或点击追踪。关闭开关停止新增明细，重新开启不回填过去的浏览；已有明细继续按当前保留期清理。缩短保留期作用于已有行。明细过期不删除每日汇总；仍保留的明细也参与事件幂等，避免较短去重缓存先过期后重复计数。

## 公开计数与私有报告

公开 JSON 只包含当前清单允许公开的累计阅读数和近 30 天热门排序，不包含 IP、UA、语言、访客摘要、Unlisted 事件或逐条流水。存在有效 0 计数时显示 0；缺失、关闭或请求失败时隐藏。

私有 HTML 保留总览、每日趋势、来源和逐页统计，并显示最近最多 1000 条事件及数据库中保留总数。历史事件保留当时标题和地址，所有请求头与文字均按 HTML 上下文转义。报告读取同一只读事务快照，失败保留上次成功输出。

私有报告不通过公开端口提供。可直接从 data/private 取回离线查看；本地试用报告也只使用明确的本机查看方式。

## 备份与恢复

停止服务后整体备份 `config.yaml`、`content/` 和 `data/`，包含数据库、持久密钥及 SQLite 辅助文件。在线数据库备份须使用 SQLite backup API 或 `VACUUM INTO`，不能单独复制正在写入的主数据库文件。

恢复时停止服务，把同一备份的数据库和密钥一并恢复，核对私有目录与文件所有权，然后启动。未知 schema、错误密钥长度、数据库损坏或不安全路径均应先检查，不能删除文件后静默开始新统计。

实现依据：[SQLite WAL](https://www.sqlite.org/wal.html)、[SQLite 一致备份](https://www.sqlite.org/backup.html)。
